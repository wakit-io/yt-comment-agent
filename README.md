# 유튜브 댓글 에이전트

> 유튜브 연애 콘텐츠를 **AI(Gemini)가 직접 분석**해 공감 댓글 초안을 만들고, 사람이 검수한 뒤 **본인 계정 브라우저에 직접 타이핑해 게시**하는 마케팅 운영 도구.
>
> (제이지그룹 AI PM 선발 — Track 2 「마케팅 AI 에이전트」 과제)

---

## 1. 제작 의도

연애 사주 서비스(예시 브랜드: **운명원**)가 유튜브 연애 콘텐츠 시청자에게 자연스럽게 다가가 자사 서비스 관심을 유도하는 **마케팅 운영을 반자동화**하는 것이 목표입니다.

핵심 가치는 세 가지입니다.

1. **맥락 이해** — 영상을 실제로 "보고" 공감하는 댓글을 쓴다.
2. **운영 효율** — 영상 찾기 → 분석 → 댓글 생성 → 게시까지 대시보드 한 곳에서.
3. **책임 있는 자동화** — 계정이 죽지 않고, 기만적이지 않으며, 사람이 마지막을 책임진다.

---

## 2. ★ 핵심 설계 결정 — "합법적이고 지속 가능한 버전"

과제 원안은 *다계정 로테이션 · 하루 상한·행동 패턴으로 탐지 회피 · 시청자인 척 무인 대량 살포* 로 댓글을 뿌리는 방식이었습니다. 이는 **은폐된 상업 홍보(애스트로터핑)** 로, YouTube 스팸·기만 정책 위반이자 **계정 영구 정지**로 직결됩니다. 단기 성과를 내더라도 브랜드 자산을 태우는 설계입니다.

그래서 **같은 목표를 달성하되, "기만·탐지 회피·대량 살포" 요소를 제거한 버전**으로 설계했습니다. 게시 자체는 과제가 요구한 **브라우저 자동 타이핑 방식**을 쓰되, 그것을 *악용*하는 부분만 덜어냈습니다.

| 구분 | 과제 원안 (거절) | 본 구현 (채택) |
|---|---|---|
| 계정 | 다계정 sock-puppet 로테이션 | **본인(브랜드) 단일 계정** |
| 탐지 | 하루 상한·패턴으로 **탐지 회피** | **탐지 회피 없음** — 정상 사용량 + 게시 간격만 |
| 게시 실행 | 무인 대량 자동 살포 | **브라우저에 직접 타이핑** + 게시 전 **사람 확인** |
| 링크/해시태그 | 무관 | **금지** (과제 규칙 + 스팸 회피, 코드에서 자동 차단) |
| 브랜드 노출 | 시청자인 척 브랜드명 심기 | ① 주제 궁금증만 남기거나 ② 공식 계정으로 **신분 밝히고** 소개 |
| 검수 | 무인 | **생성은 전자동 + 게시는 사람이 확인 1회** |

> 이 판단 자체가 결과물입니다. 시키는 대로 스팸봇을 짜는 것보다, **플랫폼 정책과 브랜드 세이프티를 읽고 제품 방향을 조정하는 것**이 AI PM의 역할이라 보았습니다.

## 3. 게시 방식 — 브라우저 직접 타이핑

실제 댓글 게시는 **Playwright로 띄운 전용 크롬 프로필**에서 이뤄집니다.

1. 전용 프로필(`.pw-profile`)로 크롬을 띄우고 — **처음 한 번** 본인 유튜브 계정으로 로그인(세션 유지).
2. 대상 영상 페이지를 열어 댓글창에 초안을 **한 글자씩 직접 타이핑** → 게시.
3. 여러 개를 고르면 **순서대로 하나씩**(동시 아님) 게시하며, 게시 사이에 간격을 둡니다.

즉, 사람이 하던 "로그인 → 댓글 달기"를 그대로 자동화한 것이며, **다계정·탐지 회피·대량 살포는 없습니다.** YouTube **Data API는 "영상 검색·메타데이터"에만** 사용합니다(게시 X).

> 참고: OAuth 공식 API 게시 경로(`commentThreads.insert`)도 코드에 함께 구현돼 있으나, 민감 스코프(`youtube.force-ssl`) 앱 검증이 필요해 **데모에서는 비활성화**하고 브라우저 타이핑을 기본 경로로 씁니다.

## 4. 동작 흐름

```
① 영상 불러오기   유튜브 검색(Data API) → 연애 콘텐츠만(음악·게임·뉴스·댓글꺼짐 자동 제외) + 필터
       ↓
② 내용 추출       Gemini가 영상을 직접 보고(화면+대사) 상황 요약 + 댓글 초안 생성 → DB 저장
       ↓
③ 영상 선택       추출된 영상에서 댓글 확인·수정·재생성·저장(지정 댓글 확정)
       ↓
④ 게시            선택한 영상에 순서대로 — 크롬에 직접 타이핑해 본인 계정으로 게시
       ↓
⑤ 작성한 댓글     게시 기록·성공/실패·랜딩 노출 관리
       ↓
⑥ 공개 랜딩       "우리가 나눈 이야기"로 게시 댓글을 정직하게 노출 + 상담 신청 접수
```

### 차별화 ① — 진짜 "영상을 본" 댓글 (맥락 이해)

메타데이터(제목·설명)만 읽는 대신, **Gemini에 유튜브 영상 URL을 직접 전달**(`fileData.fileUri`)해 화면과 대사를 분석합니다. 그래서 실제 장면·상황을 **근거로** 공감 댓글을 씁니다. (영상이 길거나 미지원이면 메타데이터로 자동 폴백)

### 차별화 ② — 책임 있는 자동화

생성·재생성은 전자동이지만, 공개로 나가는 **게시 직전에는 사람이 확인**합니다. 동시에 코드에 운영 규칙이 박혀 사고를 막습니다.

- 영상당 댓글 **1개**, 하루 상한(기본 10개)
- 한 번에 **최대 10개** 선택(토큰·스팸 방지), **게시 간 간격**
- 글자 수 제한(기본 40~120자), **링크·해시태그 자동 차단**
- "직접 이용해봤다"는 **지어낸 후기 금지**

## 5. 주요 기능

- **영상 불러오기** — 키워드 검색 + 필터(정렬·조회수·기간·"뜨는 영상"), 무한 스크롤. 음악/게임/뉴스/댓글 꺼진 영상 자동 제외. 선택 후 일괄 내용 추출(최대 10개).
- **내용 추출** — Gemini 영상 분석(단건 + 선택 일괄), 진행 모달.
- **영상 선택** — 썸네일 카드에서 댓글 확인 → 재생성 → **저장**(지정 댓글 확정), 필터(기간·상태·정렬)·검색.
- **일괄 타이핑 게시** — 여러 영상 선택 → **순서대로 크롬에 타이핑해 게시**, 진행 상황 모달(건별 완료/실패).
- **댓글 페르소나 / 브랜드 공개 모드** — 목소리·말투 설정, 일반 시청자 톤 ↔ 공식 계정 신분 공개 전환.
- **작성한 댓글** — 게시 기록, 썸네일·게시 계정·필터(전체/게시됨/실패/랜딩 노출), 운영 설정.
- **대시보드** — KPI + 최근 추출 영상 + 활동 피드.
- **공개 랜딩** — 게시 댓글을 "우리가 나눈 이야기"로 노출 + **상담 신청 폼** → 관리자 **상담 신청** 메뉴에서 확인.
- **데이터 내보내기** — 영상/댓글 CSV(엑셀) 다운로드.

## 6. 기술 스택

- **프론트/서버**: SvelteKit (Svelte 5 runes) · Vite · 서버 라우트에서 외부 API 호출
- **DB/인증**: Supabase (PostgreSQL · Auth)
- **게시(브라우저 자동화)**: **Playwright** — 전용 크롬 프로필에 본인 계정 로그인 후 댓글 직접 타이핑
- **YouTube**: Data API v3 — `search.list` · `videos.list`(영상 검색·메타데이터). *OAuth 공식 게시 경로는 선택/비활성.*
- **AI**: Google Gemini (`gemini-3.8-flash`) — 유튜브 영상 직접 분석(멀티모달), Anthropic/OpenAI 교체 가능(BYOK)
- **배포**: Vercel / Netlify 어댑터 (단, 브라우저 타이핑은 로컬 실행 전용)

키(YouTube·Gemini 등)는 **환경변수(.env)에서만** 읽으며, 에이전트·대화 경로를 거치지 않습니다.

## 7. 로컬 실행

### 사전 준비
- Node.js 20+, [Supabase CLI](https://supabase.com/docs/guides/cli), Docker
- 로컬 **Chrome**(브라우저 타이핑 게시용) + 게시에 쓸 **본인 유튜브 계정**
- Google Cloud에서 발급: **YouTube Data API v3 키**(영상 검색), **Gemini API 키**(영상 분석)

### 환경변수 (`.env`)
```bash
cp .env.example .env          # 값 채우기
# 주요 키
# SUPABASE_URL / SUPABASE_ANON_KEY / SUPABASE_SERVICE_ROLE_KEY
# YT_API_KEY                  # YouTube Data API v3 (영상 검색)
# GEMINI_API_KEY              # Google AI Studio (영상 분석)
# AI_PROVIDER=google
# (선택) GOOGLE_CLIENT_ID / SECRET / OAUTH_REDIRECT — 공식 API 게시 경로를 켤 때만
```

### 실행
```bash
supabase start               # 로컬 Supabase (API :54821 / DB :54822)
supabase db reset            # 마이그레이션 적용

cd kit
npm install
npx playwright install chromium   # (브라우저 타이핑용, 시스템 크롬 사용 시 생략 가능)
npm run dev                  # http://localhost:5210
```

### 첫 로그인 & 게시
- `/admin` 접속 → 첫 가입 계정이 운영자가 됩니다 (예: `admin@yt.local` / `admin1234`).
- **게시**: 영상 선택 → 댓글 저장 → 일괄 타이핑 게시. 처음 한 번 열린 크롬 창에서 유튜브 로그인하면 이후 세션이 유지됩니다.

> Gemini 영상 분석은 유료 티어가 필요합니다(요청당 수 원 수준).
> 브라우저 타이핑은 로컬 데스크톱 환경에서 동작합니다(서버리스 배포 X).

## 8. 차별화 요약

1. **본인 단일 계정 + 사람 검토** — 다계정 sock-puppet도, 탐지 회피도, 무인 대량 살포도 아님.
2. **영상을 실제로 분석** — 메타데이터가 아닌 화면·대사 기반 공감 댓글.
3. **책임 있는 자동화** — 전자동 생성 + 사람 검수 게시, 운영 규칙(상한·간격·링크 차단) 코드화.
4. **정직한 퍼널** — 랜딩에서 게시 댓글을 "우리 이야기"로 공개(가짜 후기 아님) → 상담 신청으로 연결.

---

*운명원은 과제용 플레이스홀더 브랜드이며, 모든 게시 기능은 운영자 본인 계정·사람 검수를 전제로 동작합니다.*
