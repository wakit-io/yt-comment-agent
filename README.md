# 유튜브 댓글 에이전트

> 유튜브 연애 콘텐츠를 **AI가 직접 분석**해 공감 댓글 초안을 만들고, 사람이 검수한 뒤 **공식 YouTube API로 본인 계정에 게시**하는 마케팅 운영 도구.
>
> (제이지그룹 AI PM 선발 — Track 2 「마케팅 AI 에이전트」 과제)

---

## 1. 제작 의도

연애 사주 서비스(예시 브랜드: **운명원**)가 유튜브 연애 콘텐츠의 시청자에게 자연스럽게 다가가, 자사 서비스에 대한 관심을 유도하는 **마케팅 운영을 반자동화**하는 것이 목표입니다.

핵심 가치는 세 가지입니다.

1. **맥락 이해** — 영상을 실제로 "보고" 공감하는 댓글을 쓴다.
2. **운영 효율** — 영상 찾기 → 분석 → 댓글 생성 → 게시까지 대시보드 한 곳에서.
3. **책임 있는 자동화** — 계정이 죽지 않고, 플랫폼 정책을 지키며, 사람이 마지막을 책임진다.

---

## 2. ★ 핵심 설계 결정 — "합법적이고 지속 가능한 버전"

과제 원안은 *다계정 로테이션 · 크롬 자동 제어로 탐지 회피 · 하루 상한 탐지 회피* 로 시청자인 척 댓글을 뿌리는 방식이었습니다. 하지만 이는 **은폐된 상업 홍보(애스트로터핑)** 로, YouTube 스팸·기만 콘텐츠 정책 위반이자 **계정 영구 정지**로 직결됩니다. 단기 성과를 내더라도 브랜드 자산을 태우는 설계입니다.

그래서 **같은 목표를 달성하되 밴 리스크를 제거한 버전**으로 설계했습니다.

| 구분 | 과제 원안 (거절) | 본 구현 (채택) |
|---|---|---|
| 게시 방식 | 크롬 프로필 자동 타이핑 (봇) | **공식 YouTube Data API** (`commentThreads.insert`) |
| 계정 | 다계정 sock-puppet + 탐지 회피 | **본인(브랜드) 단일 계정**, OAuth 정식 인증 |
| 링크/해시태그 | 무관 | **금지** (과제 규칙 + 스팸 회피, 코드에서 자동 차단) |
| 브랜드 노출 | 시청자인 척 브랜드명 심기 | ① 주제 궁금증만 남기거나 ② **공식 계정으로 신분 밝히고** 소개 |
| 검수 | 무인 대량 살포 | **생성은 전자동 + 게시는 사람이 확인 1회** |

> 이 판단 자체가 결과물입니다. 시키는 대로 스팸봇을 짜는 것보다, **플랫폼 정책과 브랜드 세이프티를 읽고 제품 방향을 조정하는 것**이 AI PM의 역할이라 보았습니다.

## 3. 동작 흐름

```
① 영상 불러오기   유튜브 검색(공식 API) → 연애 콘텐츠만(음악·게임·뉴스·댓글꺼짐 자동 제외)
       ↓
② 내용 추출       Gemini가 영상을 직접 보고(화면+대사) 상황 요약 + 댓글 초안 생성 → DB 저장
       ↓
③ 영상 선택       추출된 영상에서 댓글 확인·수정·재생성 → 본인 계정으로 게시
       ↓
④ 작성한 댓글     게시 기록·성공/실패·랜딩 노출 관리
       ↓
⑤ 공개 랜딩       "유튜브에서 나눈 이야기"로 게시 댓글을 정직하게 노출(제3자 후기 아님)
```

### 차별화 ① — 진짜 "영상을 본" 댓글 (맥락 이해)

메타데이터(제목·설명)만 읽는 대신, **Gemini에 유튜브 영상 URL을 직접 전달**(`fileData.fileUri`)해 화면과 대사를 분석합니다. 그래서 "3분쯤 그 장면" 같은 **실제 내용을 근거로** 공감 댓글을 씁니다. (영상이 길거나 미지원이면 메타데이터로 자동 폴백)

### 차별화 ② — 책임 있는 자동화

생성·재생성·게시는 원클릭이지만, 공개로 나가는 **게시 직전에는 사람이 확인**합니다. 동시에 코드에 운영 규칙이 박혀 있어 사고를 막습니다.

- 영상당 댓글 **1개**, 하루 상한(기본 10개)
- 글자 수 제한(40~120자), **링크·해시태그 자동 차단**
- "직접 이용해봤다"는 **지어낸 후기 금지**

## 4. 주요 기능

- **영상 불러오기** — 키워드 검색 + 조회수 필터, 무한 스크롤, 로딩 게이지. 음악/게임/뉴스/댓글 꺼진 영상 자동 제외.
- **내용 추출** — AI 영상 분석(단건 + 선택 일괄 배치), 진행률 표시.
- **영상 선택** — 썸네일 카드에서 바로 댓글 확인 → 재생성 → **게시**(빠른 모달), 또는 상세에서 꼼꼼히 편집.
- **브랜드 공개 모드** — 끄면 일반 시청자 톤(브랜드명 없이 궁금증), 켜면 공식 계정 톤(신분 공개).
- **댓글 페르소나** — 댓글의 목소리·말투를 프리셋/자유 입력으로 설정.
- **작성한 댓글** — 게시 기록, 필터(전체/게시됨/실패/랜딩 노출), 운영 설정.
- **대시보드** — KPI + 최근 추출 영상 썸네일 + 활동 피드.
- **공개 랜딩** — 게시한 댓글을 "우리가 나눈 이야기"로 정직하게 노출.
- **데이터 내보내기** — 영상/댓글 데이터 CSV(엑셀) 다운로드.

## 5. 기술 스택

- **프론트/서버**: SvelteKit 3 (Svelte 5 runes) · Vite 8 · 단일 서버 라우트로 외부 API 호출
- **DB/인증**: Supabase (PostgreSQL · Auth)
- **YouTube**: Data API v3 — `search.list` · `videos.list` · `commentThreads.list/insert`, OAuth 2.0 (`youtube.force-ssl`)
- **AI**: Google Gemini (`gemini-3.8-flash`) — 유튜브 영상 직접 분석(멀티모달), Anthropic/OpenAI 교체 가능(BYOK)
- **배포**: Vercel / Netlify 어댑터

키(YouTube·Gemini·OAuth)는 **배포 환경변수(.env)에서만** 읽으며, 에이전트·대화 경로를 거치지 않습니다.

## 6. 로컬 실행

### 사전 준비
- Node.js 20+, [Supabase CLI](https://supabase.com/docs/guides/cli), Docker
- Google Cloud에서 발급: **YouTube Data API v3 키**, **OAuth 2.0 웹 클라이언트**(리디렉션 `http://localhost:5210/auth/youtube/callback`), **Gemini API 키**

### 환경변수 (`.env`)
```bash
cp .env.example .env          # 값 채우기
# 주요 키
# SUPABASE_URL / SUPABASE_ANON_KEY / SUPABASE_SERVICE_ROLE_KEY
# YT_API_KEY                  # YouTube Data API v3
# GEMINI_API_KEY              # Google AI Studio
# GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET / GOOGLE_OAUTH_REDIRECT
# AI_PROVIDER=google
```

### 실행
```bash
supabase start               # 로컬 Supabase (API :54821 / DB :54822)
supabase db reset            # 마이그레이션 적용

cd kit
npm install
npm run dev                  # http://localhost:5210
```

### 첫 로그인
`/admin` 접속 → 첫 가입 계정이 운영자가 됩니다 (예: `admin@yt.local` / `admin1234`).
설정(또는 헤더 계정 칩)에서 **YouTube 계정 연결**(OAuth) 후 게시 가능.

> OAuth 동의 화면이 "테스트" 상태이면 본인 Google 계정을 **테스트 사용자**로 등록해야 합니다.
> Gemini는 영상 분석에 유료 티어가 필요합니다(요청당 수 원 수준).

## 7. 차별화 요약

1. **봇이 아닌 공식 API** — 안정적이고 안 깨지며, 정책 위반이 아닌 정식 경로.
2. **영상을 실제로 분석** — 메타데이터가 아닌 화면·대사 기반 공감 댓글.
3. **책임 있는 자동화** — 전자동 생성 + 사람 검수 게시, 운영 규칙 코드화.
4. **정직한 퍼널** — 랜딩에서 게시 댓글을 "우리 이야기"로 공개(가짜 후기 아님).

---

*운명원은 과제용 플레이스홀더 브랜드이며, 모든 게시 기능은 운영자 본인 계정·사람 검수를 전제로 동작합니다.*
